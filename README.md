# workspace [![Tester](https://github.com/hashcat26/workspace/actions/workflows/tester.yml/badge.svg)](https://github.com/hashcat26/workspace/actions/workflows/tester.yml) [![Dependabot](https://img.shields.io/badge/Dependabot-enabled-0366D6?logo=dependabot&logoColor=959DA5&labelColor=30373D)](https://github.com/hashcat26/workspace/actions/workflows/dependabot/dependabot-updates)
Portable coding workspace generator and updater written in [PowerShell](https://www.powershellgallery.com).

Getting the files:
---------------------------------
To get the files, run `curl -kO https://raw.githubusercontent.com/hashcat26/workspace/master/workspace.ps1`.

Initializing workspace:
---------------------------------
To perform workspace initialization, do `powershell -c "./workspace.ps1"`.
